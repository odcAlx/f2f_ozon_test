# F2F Bank - Тестовое задание

F2F Bank - простое веб-приложение, имитирующее сервис переводов между пользователями в стиле СБП. Пользователи могут регистрироваться, входить в систему, пополнять баланс и отправлять переводы по номеру телефона

---

## Как запустить приложение

### 1. Перейдите в корень проекта
```bash
cd <папка репозитория>
```
### 2. Поднимите контейнеры Docker
```bash
docker compose up -d --build
```
### 3. Остановите приложение по окончании работы
- Обычная остановка

    ```bash
    docker compose down
    ```
- Полный сброс вместе с данными базы данных

    ```bash
    docker compose down -v
    ```
*Перед запуском следует убедиться, что Docker установлен и запущен Docker Desktop*  
*Приложение будет доступно по адресу [http://localhost](http://localhost)*

## Как запустить тесты

### 1. Установите необходимые зависимости

```bash
npm install
```

### 2. Запустите тесты

- Запустить тесты в фоновом режиме

    ```bash
    npx playwright test
    ```
- Запустить тесты в UI режиме

    ```bash
    npx playwright test -ui
    ```
- Сгенерировать отчет в HTML

    ```bash
    npx playwright show-report
    ```
